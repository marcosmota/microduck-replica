# Mapa do ecossistema Microduck

> 🌐 Tradução não oficial para pt-BR do [original](https://github.com/fanhao375/microduck-replica). Em caso de divergência, vale o original. Licença: CC BY-NC-SA 4.0 (texto alterado: traduzido do chinês/inglês).

**Português (pt-BR)** · [English](ecosystem.en.md)

O material do Microduck está espalhado por várias organizações do GitHub e por três tipos de recurso do HuggingFace.
**Os repositórios oficiais de hardware são especialmente fáceis de passar despercebidos** (não estão no repositório principal e têm o prefixo `elec_`).

Este índice explica **o que cada item é e para que serve**. Dados de **2026-09-04**; o número de estrelas muda.

---

## 1. Repositórios oficiais (pollen-robotics)

### Os dois principais

| Repositório | Estrelas | Licença | O que é |
|---|---|---|---|
| [**microduck**](https://github.com/pollen-robotics/microduck) | 6982 | Apache-2.0 | **Runtime embarcado.** Escrito em Rust, é todo o software que roda no robô: laço de controle a 50Hz, atualizador, BLE, câmera/WebRTC, ToF, voz. Para ler as especificações de hardware, também é aqui: caminhos de dispositivo, endereços I²C e registradores estão todos fixos no código |
| [**microduck_rl**](https://github.com/pollen-robotics/microduck_rl) | 1668 | Apache-2.0 | **Ambiente de treinamento por aprendizado por reforço** (baseado em mjlab). **Os 47 STLs e o MJCF completo estão aqui**, a única fonte de toda a informação geométrica |

### Hardware (os dois que passam despercebidos)

| Repositório | Estrelas | Licença | O que é |
|---|---|---|---|
| [**elec_RPI_Robot_HAT**](https://github.com/pollen-robotics/elec_RPI_Robot_HAT) | 15 | Apache-2.0 | ⭐ **Projeto open source completo da placa HAT.** Esquemático e PCB em KiCad 9, Gerber, BOM, coordenadas de montagem, STEP, todos os manuais dos componentes. **Não é preciso desenhar a placa: baixe `production/` e mande fabricar** (placa de 4 camadas) |
| [**lib_KiCAD**](https://github.com/pollen-robotics/lib_KiCAD) | 3 | — | Biblioteca KiCad da Pollen de símbolos/footprints/modelos 3D. **É obrigatório instalá-la antes de abrir o projeto acima**, senão aparece uma enxurrada de símbolos não resolvidos |

> Muita gente acha que "o hardware do Microduck não é aberto": **a placa HAT é, na verdade, aberta**, só não está no repositório principal.
> O que realmente não foi publicado é a placa `imu_to_dxl`, o CAD mecânico editável e a BOM do robô completo.

### Complementares

| Repositório | Estrelas | O que é |
|---|---|---|
| [rustypot](https://github.com/pollen-robotics/rustypot) | 56 | Biblioteca de comunicação Dynamixel (Rust). O runtime a usa para falar com os servos; o `xl330.rs` contém a tabela completa de registradores |
| [microduck-gst-plugins](https://github.com/pollen-robotics/microduck-gst-plugins) | 13 | Plugins GStreamer aarch64 pré-compilados: codificador de hardware Rockchip MPP + WebRTC |
| `duck_detector` | — | ⚠️ **Não é público** (404). Repositório de treinamento do modelo de detecção para NPU; a documentação oficial o cita, mas não há acesso externo |

`beak-throw` (arremessar objetos com o bico), `electric-slide`, `swing` (balanço), `stilts` (pernas de pau), `running`.

> O upstream oferece o comando `uv run publish`, que publica diretamente no Hub a política que você treinou.

## Por onde começar

| O que você quer fazer | Para onde ir |
|---|---|
| Sentir o robô primeiro | [Simulador web oficial](https://huggingface.co/spaces/pollen-robotics/microduck-simulator), abra e já dá para brincar |
| Ver como ele é e como se monta | [Modelos e instruções de instalação do repositório de CAD](https://github.com/fanhao375/microduck-replica-cad); as renderizações de montagem deste repositório servem apenas como referência de análise do upstream |
| Imprimir peças | [Repositório de CAD](https://github.com/fanhao375/microduck-replica-cad); [aviso de versões](../print/README.md) |
| Entender a parte eletrônica | [`docs/硬件方案逆向.md`](硬件方案逆向.md) neste repositório |
| Fazer a placa HAT | `production/` de [`elec_RPI_Robot_HAT`](https://github.com/pollen-robotics/elec_RPI_Robot_HAT); não esqueça de instalar antes o `lib_KiCAD` |
| Treinar sua própria política | [`microduck_rl`](https://github.com/pollen-robotics/microduck_rl); sem placa NVIDIA, use o [microduck-lab](https://github.com/jonathanhawkins/microduck-lab) |
| Ler as especificações de hardware | Código-fonte do [`microduck`](https://github.com/pollen-robotics/microduck): **o código é a folha de especificações** |
